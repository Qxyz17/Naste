# Naste

![Preview](/images/image2.png)

A modern Minecraft **1.8.9** client, built on Forge with a custom OpenGL UI.

## Features

* Fluid, animated ClickGUI — rounded, glowing, fully themeable
* Combat / Movement / Render / Player / Misc module categories
* Custom HUD and visual suite

## Building

```bash
./gradlew build
```

The output jar is in `build/libs/`.
